# vexth Tool – Configuration Guide

## 1. Custom Wordlist Directory

vexth Tool allows users to choose their own wordlist file location.

The default Wi-Fi wordlist path is defined in `vexth_toolVx.py`.

### Where to change the path

Open `vexth_toolVx.py` and go to **line 159**.

You will find:

```python
WIFI_WORDLIST = os.path.join(os.path.dirname(os.path.abspath(__file__)), "BIG-WPA-LIST-2")
```

Replace `"BIG-WPA-LIST-2"` with your preferred file path.

**Example – Windows:**

```python
WIFI_WORDLIST = "C:/Users/YourName/Documents/wordlists/passwords.txt"
```

**Example – Linux:**

```python
WIFI_WORDLIST = "/home/yourname/wordlists/passwords.txt"
```

**Example – Relative path:**

```python
WIFI_WORDLIST = os.path.join(os.path.dirname(os.path.abspath(__file__)), "wordlists", "passwords.txt")
```

### 2. GUI Default Path

Go to **line 853**.

You will find:

```python
("Wordlist path:", WIFI_WORDLIST),
```

This line automatically uses the path defined at line 159.

You normally do not need to change this line unless you want to modify how the input field is initialized.

When using the Brute WiFi tool, you can also enter a different wordlist path directly in the GUI.

### 3. Capture File Location

When selecting Brute WiFi, the program also asks for:

```text
Capture file (.cap/.hccapx) path:
```

This path is entered directly by the user in the GUI. It does not have a fixed default directory.

### 4. Important Notes

- Make sure the specified files exist.
- Use valid paths for your operating system.
- Make sure Liter Tool has permission to access the selected files.
- If you move a wordlist, update its path or enter the new location in the GUI.
- Do not upload private files, personal data, or sensitive wordlists to GitHub.
- Only perform password audits on networks you own or are explicitly authorized to test.

### 5. Source Code Line References

The line numbers in this guide refer to the version of `vexth_tool.py` supplied with this configuration guide. They may change in future versions.
